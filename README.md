# Field Programme Catalogue

Public programme for the Cinder & Vale Field Studio. Each Markdown file under `catalog/`
describes one field session.

Front-matter house style:

- `title`, `permalink`, `date`, `publication_status`
- `city`, `venue`
- `hosturl`, `docsurl`, `signupurl`
- `toolkit_ref` — directory of the toolkit inside the toolkit source repository
- `repo_url` — public source link (the toolkit's directory), added once the toolkit is released

Entries are edited by hand on the `main` branch.
